⚡ Conexão Supabase (Nuvem Automática)

Gratuito

Conecte seu projeto gratuito do Supabase para ter login e banco de dados online permanente.

ℹ️ Como pegar essas chaves no Supabase e criar as tabelas
  1. Crie uma conta gratuita em supabase.com.
  2. Clique em "New Project".
  3. Em Project Settings > API, copie a URL e a anon key.
  4. No menu SQL Editor, cole o código do script supabase_schema.sql e clique em Run.
-- Esquema completo de tarefas, agendas e chronos_userdata disponível em 'supabase_schema.sql'
create table if not exists public.chronos_userdata (
  user_id text primary key,
  tasks jsonb default '[]'::jsonb,
  habits jsonb default '[]'::jsonb,
  reflections jsonb default '[]'::jsonb,
  updated_at timestamptz default now()
);
alter table public.chronos_userdata enable row level security;
create policy "Allow all operations for users" on public.chronos_userdata for all using (true) with check (true);
